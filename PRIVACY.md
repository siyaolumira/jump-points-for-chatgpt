# Privacy Policy for Jump Points for ChatGPT

Last updated: September 5, 2026

Jump Points for ChatGPT is a browser extension that provides position-based navigation within signed-in ChatGPT conversations.

This privacy policy explains what information the extension handles, why it is needed, and how it is stored.

## Data handled by the extension

Jump Points handles a limited amount of information from ChatGPT conversation pages when you create and use Jump Points.

A saved Jump Point may include:

- The text you selected to create the Jump Point
- A limited amount of surrounding text used to distinguish the selected text from similar text elsewhere in the conversation
- The name you give the Jump Point
- The ChatGPT conversation identifier and URL
- An approximate scroll position
- The time the Jump Point was created

The extension may also temporarily read rendered text and page structure within ChatGPT conversations in order to locate a saved position and navigate back to it.

Because selected and surrounding text may come from ChatGPT conversations, this information may constitute personal communications or website content depending on what the user has entered into the conversation.

## How the data is used

The information handled by Jump Points is used only to provide the extension's navigation functionality.

Specifically, it is used to:

- Create Jump Points from user-selected text
- Distinguish between repeated or similar text within a conversation
- Restore saved positions within ChatGPT conversations
- Navigate between Jump Points in the same or different ChatGPT conversations
- Display and manage the user's three Jump Points

Jump Points does not use this information for advertising, profiling, analytics, creditworthiness, lending decisions, or purposes unrelated to the extension's navigation functionality.

## Data storage

Saved Jump Point data is stored locally using Chrome extension storage.

Jump Points does not operate a remote backend for storing Jump Point data.

## Data transmission and sharing

Jump Points does not transmit saved Jump Point data to an external server operated by the developer.

Jump Points does not sell user data.

Jump Points does not transfer user data to third parties for advertising, marketing, analytics, profiling, creditworthiness, lending, or other unrelated purposes.

## Website access

Jump Points is designed to operate only on ChatGPT pages covered by the extension's declared permissions.

The extension requires access to ChatGPT conversation pages so that it can:

- Detect user-selected text
- Read nearby text needed for position matching
- Locate saved positions in rendered conversation content
- Navigate through long or virtualized conversations
- Display the Jump Points interface

Jump Points does not request access to unrelated websites.

## Accounts and authentication

Jump Points does not provide or require its own user account.

The extension does not collect or store ChatGPT passwords, authentication credentials, or other login credentials.

Jump Points currently operates on signed-in ChatGPT conversations. Authentication to ChatGPT is handled by ChatGPT and is not managed by this extension.

## Data retention and deletion

Saved Jump Points remain in Chrome extension storage until they are replaced, removed by the user, or the extension's stored data is otherwise cleared.

Removing a Jump Point removes that Jump Point from the extension's saved Jump Point list.

Users can also remove the extension from Chrome to stop the extension from accessing ChatGPT pages.

## Remote code

Jump Points does not use remotely hosted JavaScript or WebAssembly code. The extension's executable code is included in the extension package.

## Changes to this privacy policy

This privacy policy may be updated if the extension's functionality or data practices change.

Any updated version will be published in this repository with a revised "Last updated" date.
